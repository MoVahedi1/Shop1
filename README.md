# VELO — Curated Lifestyle Store 🛍️

A modern, single-page e-commerce storefront built with vanilla JavaScript and Tailwind CSS. Features a fully functional cart, live search, category filtering, and smooth micro-interactions — all without any framework.

## 🔗 Live Demo
[velo-store.netlify.app](https://movahedi1.github.io/Shop1/Shop)

## ✨ Features

- 🛒 **Full cart system** — add, remove, change quantity, live subtotal
- 🔍 **Live search** — instant results as you type
- 🎯 **Category filtering & sorting** — by price, rating, newest
- 📱 **Fully responsive** — mobile-first, works on all screen sizes
- 🎨 **Modern UI** — dark theme, animated blobs, floating tags, scroll reveals
- 🔔 **Toast notifications** — non-blocking feedback for every action
- ⚡ **Zero dependencies** — no React, no Vue. Pure HTML, Tailwind, and JavaScript
- ♿ **Accessible** — ARIA labels, keyboard support (ESC closes modals), reduced-motion support

## 🛠️ Tech Stack

| Layer | Tech |
|-------|------|
| Markup | HTML5 |
| Styling | Tailwind CSS (CDN) + custom CSS animations |
| Logic | Vanilla JavaScript (ES6+) |
| Icons | Font Awesome 6 |
| Fonts | Space Grotesk, DM Sans |
| Images | Picsum (placeholder) |
